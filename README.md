This project is a short horror game I developed in Unity with the goal of creating a complete experience that other people could play and enjoy. It helped me improve my C# skills while gaining hands-on experience with game development, level design, and interactive gameplay.

The game is a ~20-minute exploration-based experience set inside a mysterious house. The main objective is to escape by exploring different rooms, solving small puzzles, and finding clues. The atmosphere plays a big role, with the house feeling alive and constantly watching the player. Depending on the choices made during the game, there are three different possible endings.

The game can be downloaded and played in https://hyperrsmash.itch.io/nooneawaits for free.
